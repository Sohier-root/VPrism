Utilisation des données

Comparer les données

  1. Cliquer sur le bouton "Comparer" afin de lancer la comparaison
  2. Les données incorrect devienne rouge sur l'arbre de données de références
✅ Le saviez vous : La comparaison ce fait uniquement sur la référence.
Si une donnée est présente uniquement dans les données testé, elle ne sera pas détecté.

Résolution des données

Merge

Le système donne la possibilité d'ajouter un item depuis les données de référence vers les données testées. Pour cela il vous faut faire:
  • Clique droit sur l'item voulu
  • Selection de l'option "Merge"
  • L'item devrait maintenant apparaitre dans les données testées (affichage de droite)

Replace

Le système donne la possibilité de remplacer un item depuis les données de référence vers les données testées. Pour cela il vous faut faire:
  • Clique sur l'item de référence voulu
  • En pressant la touche Ctrl, clique sur l'item testé voulu (les deux items doivent être sélectionné)
  • Clique droit sur l'item de référence
  • Selection de l'option "Replace"
  • L'item de référence devrait maintenant remplacer l'item testé
