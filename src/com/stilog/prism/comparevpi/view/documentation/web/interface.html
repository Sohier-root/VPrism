Interface utilisateur

Barre d'outils

  •  Afficher seulement les différences (faire la comparaison au préalable)
  •  Synchroniser les deux affichages
  •  Génère un VPI/VPS a partir de l'affichage de droite (Affichage testé), ainsi qu'a partir des données du VPS/VPI importé
  •  Intervertir les deux affichages (Les données de comparaison sont remises a zéro)

Zone d'affichages

  1. Zone de fichier. Importez un VPI/VPS en cliquant sur le bouton "Importer".
  2. Zone d'affichages. L'arbre des données du VPI s'affiche ici.
💡 Astuce : La zone d'affichage de gauche contiendra le VPI de référence.
La zone d'affichage de droite contiendra le VPI testé.
