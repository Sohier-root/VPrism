Module Analyse VPI

Le module Analyse VPI permet d'ouvrir et d'explorer un fichier VPI ou VPS de manière autonome, sans avoir besoin d'un second fichier de comparaison. Il est accessible depuis la barre de navigation principale en cliquant sur « Analyse VPI ».

Onglet « Arbre VPI/VPS »

Importer un fichier

  1. Cliquez sur le bouton « Importer… » en haut de l'onglet.
  2. Sélectionnez un fichier .vpi ou .vps depuis le sélecteur.
  3. Une fenêtre de chargement s'affiche le temps du traitement.
  4. L'arbre se peuple automatiquement avec la structure du fichier importé.

Navigation dans l'arbre

L'arbre affiche la hiérarchie complète du fichier VPI, organisée par fichier de données, puis par entités, paramètres et attributs. Cliquez sur les nœuds pour les déplier ou les replier.

Visualisation des filtres

Un double-clic sur un nœud de type filtre (dans les sections Filtre Ressources ou Filtre Événements) ouvre une fenêtre de visualisation des conditions du filtre avec un code couleur par opérateur :

  • Vert — égalité (=)
  • Bleu — comparaison (<, >, ≤, ≥)
  • Violet — appartenance (IN)
  • Jaune/Ocre — texte (LIKE, contient…)
  • Rouge — négation (NOT, !=)
💡 Astuce : Seuls les nœuds appartenant aux sections Filtre Ressources ou Filtre Événements ouvrent une fenêtre de filtre. Un double-clic sur un autre type de nœud n'a pas d'effet.

Onglet « Dépendances »

L'onglet Dépendances s'active automatiquement dès qu'un fichier est importé dans l'onglet Arbre. Il affiche un diagramme interactif représentant les relations entre tous les éléments du VPI, organisés en 8 colonnes :

  • Dimension — les dimensions du VPI
  • Hiérarchie — les hiérarchies
  • Filtres — Filtre Ressource et Filtre Événement
  • Imports — Import Ressource et Import Événement
  • Exports — Export Ressource et Export Événement

Navigation dans le diagramme

  • Molette souris — zoom avant / arrière
  • Glisser (drag) — déplacer la vue (pan)
  • Clic sur un nœud — sélectionner et mettre en évidence ses dépendances
  • Survol (hover) — afficher une infobulle avec les détails du nœud
  • Bouton « ⌖ Reset vue » — réinitialise le zoom et la position à l'état initial

Recherche

La barre de recherche en haut du diagramme filtre les nœuds en temps réel. Tapez le nom (ou une partie du nom) d'un élément pour le retrouver et le mettre en évidence. Effacez le champ pour revenir à l'affichage complet.

Légende des couleurs

Chaque type d'élément possède sa propre couleur dans le diagramme :

  • Bleu — Dimension
  • Vert — Hiérarchie
  • Orange — Filtre Ressource
  • Rose/Rouge — Filtre Événement
  • Violet — Import Ressource
  • Cyan — Import Événement
  • Magenta — Export Ressource
  • Teal — Export Événement
✅ Le saviez-vous : Les dépendances d'un nœud sélectionné sont mises en évidence en jaune pour faciliter la lecture des relations dans des VPI complexes.
⚠ Attention : L'onglet Dépendances reste vide tant qu'aucun fichier n'a été importé dans l'onglet Arbre VPI/VPS.

Onglet « Historique »

L'onglet Historique est disponible uniquement pour les fichiers .vps. Il permet d'explorer l'intégralité des modifications enregistrées : création, modification et suppression de ressources, d'événements et d'éléments de configuration.

Chargement

Le traitement se fait en arrière-plan en plusieurs étapes : extraction de history.txt et historytracker.txt, résolution des noms lisibles depuis le VPS, puis indexation en streaming de l'historique détaillé. Cette approche permet de gérer des fichiers de plusieurs gigaoctets sans impact sur les performances — le détail des modifications est chargé à la demande au clic.

Filtres communs

La barre du haut s'applique aux trois sous-onglets simultanément : recherche globale, Modifié par, Créé par, filtres de date sur modification et création (le, après le, avant le, cette semaine…), et Afficher supprimés pour inclure les entrées dont l'entité n'existe plus dans le VPS (affichées en italique grisé par défaut).

Sous-onglet « Dimensions »

Historique des ressources (EventResourceX). Le nom est résolu depuis les rubriques d'identification du modèle de dimension. Le type affiché est le nom de la dimension (ex. OUTSOURCE, NETWORK ACTIVITIES). Filtres spécifiques : type de dimension.

Sous-onglet « Événements »

Historique des PlanningEvent. Chaque événement est rattaché à son arbre de création automatiquement : toutes les dimensions obligatoires de l'arbre doivent être présentes, et aucune dimension étrangère ne doit figurer sur l'événement. Le label affiche les dimensions-clés (ex. NETWORK-EST | Activity 26). Filtres spécifiques : type d'arbre et dates de l'événement (commence/finit avant/après le, actif le…).

Sous-onglet « Autres »

Historique de configuration : exports, imports, filtres VP, formulaires, etc. Filtre spécifique : type.

Panneau de détail

Un clic sur n'importe quelle ligne affiche le détail des propriétés modifiées dans le panneau du bas. Les modifications simultanées (batch, imports…) sont regroupées par date et utilisateur avec un en-tête coloré.

💡 Note : L'onglet Historique reste vide si le fichier importé est un .vpi — seuls les .vps contiennent des données historiques.
