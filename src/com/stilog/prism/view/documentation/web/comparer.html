Utilisation des données

Comparer les données

  1. Importez le fichier VPI de référence (zone gauche) puis le fichier testé (zone droite).
  2. Cliquez sur le bouton « Comparer » en bas de l'application pour lancer l'analyse.
  3. Les données présentant des différences apparaissent en rouge dans l'arbre de référence (gauche).
✅ Le saviez-vous : La comparaison s'effectue uniquement depuis la référence.
Si une donnée est présente uniquement dans le fichier testé, elle ne sera pas détectée comme différence.

Afficher seulement les différences

Après avoir lancé la comparaison, le bouton Afficher seulement les différences (barre d'outils) masque tous les nœuds identiques et ne conserve que ceux présentant un écart. Cliquer à nouveau sur ce bouton restaure l'affichage complet.

Résolution des données

Deux actions permettent de corriger les différences directement depuis l'interface : Merge et Replace.

Merge — ajouter un élément manquant

Le Merge permet d'ajouter un élément présent dans la référence (gauche) mais absent du fichier testé (droite).

  • Faites un clic droit sur l'élément voulu dans l'arbre de gauche.
  • Sélectionnez l'option « Merge ».
  • L'élément apparaît maintenant dans l'arbre testé (affichage de droite).

Replace — remplacer une valeur incorrecte

Le Replace permet de remplacer un élément du fichier testé par la valeur de référence correspondante.

  • Cliquez sur l'élément de référence voulu (arbre gauche).
  • En maintenant la touche Ctrl, cliquez sur l'élément testé à remplacer (arbre droit). Les deux éléments doivent être sélectionnés simultanément.
  • Faites un clic droit sur l'élément de référence.
  • Sélectionnez l'option « Replace ».
  • L'élément testé est remplacé par la valeur de référence.
💡 Astuce : Après un Merge ou un Replace, vous pouvez générer un nouveau fichier VPI/VPS via le bouton dédié dans la barre d'outils, afin d'exporter le résultat corrigé.

Intervertir les affichages

Le bouton Intervertir (barre d'outils) échange les rôles des deux fichiers : le fichier testé devient la référence et vice versa. Les résultats de comparaison sont remis à zéro et une nouvelle comparaison doit être lancée.

Générer un nouveau fichier VPI/VPS

Une fois les modifications appliquées (Merge, Replace), vous pouvez exporter l'arbre testé sous forme d'un nouveau fichier VPI ou VPS.

  1. Cliquez sur le bouton Générer un VPI/VPS dans la barre d'outils.
  2. Un sélecteur de dossier s'ouvre : choisissez le dossier de destination.
  3. Le fichier est généré automatiquement à partir des données de l'arbre testé et du VPS/VPI source importé.
⚠ Attention : Le bouton de génération n'est actif qu'après le chargement complet des deux fichiers (attendre la fin du dézipage en arrière-plan).
