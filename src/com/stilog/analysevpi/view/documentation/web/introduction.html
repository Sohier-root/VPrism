📖 VP Comparator - Documentation

Bienvenue

VP Comparator est un outil de comparaison de fichiers VPI/VPS qui vous permet de :

  • Comparer deux fichiers VPI côte à côte avec une visualisation claire
  • Identifier rapidement les différences entre les fichiers
  • Synchroniser les vues pour une navigation facilitée
  • Filtrer l'affichage pour ne voir que les différences
  • Générer de nouveaux fichiers VPI basés sur vos modifications
💡 Astuce : Utilisez les boutons de la barre d'outils en haut de l'application pour accéder rapidement aux fonctionnalités principales.

🚀 Démarrage rapide

  1. Cliquez sur Importer... dans la zone "Référence" (gauche)
  2. Sélectionnez votre fichier VPI de référence
  3. Attendez le chargement du fichier
  4. Cliquez sur Importer... dans la zone "Testé" (droite)
  5. Sélectionnez le fichier VPI à comparer
  6. Cliquez sur le bouton Comparer en bas de l'application
  7. Les différences s'afficheront automatiquement dans les deux arbres
