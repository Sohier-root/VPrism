📖 VP Comparator - Documentation

Bienvenue

VP Comparator est un outil de comparaison et d'analyse de fichiers VPI/VPS qui vous permet de :

  • Comparer deux fichiers VPI côte à côte avec une visualisation claire des différences
  • Identifier rapidement les écarts entre un fichier de référence et un fichier testé
  • Synchroniser les vues pour une navigation facilitée dans les deux arbres
  • Filtrer l'affichage pour ne voir que les différences
  • Visualiser les filtres VP et les comparer côte à côte
  • Corriger les différences par Merge ou Replace directement dans l'interface
  • Générer de nouveaux fichiers VPI/VPS basés sur vos modifications
  • Analyser un fichier VPI seul via le module Analyse VPI
💡 Astuce : Le bouton Aide et documentation est accessible en permanence depuis la barre de navigation principale, quel que soit le module actif.

🚀 Démarrage rapide

  1. Cliquez sur Importer... dans la zone « Référence » (gauche)
  2. Sélectionnez votre fichier VPI de référence (.vpi ou .vps)
  3. Attendez la fin du chargement
  4. Cliquez sur Importer... dans la zone « Testé » (droite)
  5. Sélectionnez le fichier VPI à comparer
  6. Cliquez sur le bouton « Comparer » en bas de l'application
  7. Les différences s'affichent en rouge dans l'arbre de référence

🧭 Modules disponibles

  • Comparaison — Compare deux fichiers VPI/VPS côte à côte. Permet le Merge, le Replace et la génération d'un nouveau fichier.
  • Analyse VPI — Analyse et visualise un fichier VPI seul, avec navigation dans l'arbre des données et le diagramme de dépendances.
